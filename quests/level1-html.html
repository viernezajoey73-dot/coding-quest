🏡 Level 1: Village of Markup

Build the skeleton of every webpage.

Quest 1.1: Lay Your Foundation

HTML = the skeleton of all websites. Copy this into a file named mypage.html and open it in your browser:

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>I built my first webpage!</p>
</body>
</html>

Quest 1.2: Headings & Paragraphs

Use <h1> to <h6> and <p> to write an introduction about yourself.

Quest 1.3: Add Links & Images

Use <a href="url"> for links and <img src="url" alt="desc"> for pictures.
