👗 Level 2: Style Kingdom

Give your page an outfit — colors, fonts, and layout magic.

Quest 2.1: Meet CSS — Your Design Tool

CSS = Cascading Style Sheets. It tells HTML how to look.

<style>
  body { background: darkblue; color: white; }
  h1 { color: gold; font-size: 2rem; }
</style>

Add this inside your <head> and watch the magic happen! ✨

Quest 2.2: Choose Your Colors

You can use color names, hex codes, or RGB values:

color: gold;
color: #fbbf24;
color: rgb(251, 191, 36);

Try changing your page background to your favorite color!

Quest 2.3: Sizes & Spacing

h1 {
  font-size: 2.5rem;    /* Text size */
  margin: 2rem;        /* Space OUTSIDE */
  padding: 1rem;       /* Space INSIDE */
}

Make your heading big and bold — give it room to shine!

Boss Battle: Redesign Your Profile Page 🐉
